  <action>
Per D-05: Rewrite Compressor::process() in src/audio/dsp.rs starting at L840.

First, implement RMS detection. In process(&mut self, frame: &mut [f64]):
1. Push a clone of the current input frame into self.lookahead.push_back(frame.to_vec()).
2. While self.lookahead.len() > self.lookahead_samples: self.lookahead.pop_front().
3. If self.lookahead.len() < self.lookahead_samples: return early (buffer not full yet).

Find the future peak by scanning ALL samples in the lookahead buffer:
```rust
let future_peak = self.lookahead.iter().flatten().map(|s| s.abs()).max_by(|a, b| a.partial_cmp(b).unwrap()).unwrap_or(0.0);
```

Compute RMS of the lookahead buffer (stereo-linked, max of channels):
```rust
let rms_sq = self.lookahead.iter().flatten().map(|s| s * s).sum::<f64>() / (self.lookahead.len() * 2) as f64; // approximate for stereo
let rms = rms_sq.sqrt().max(1e-10);
```
Use the maximum between future_peak and rms for the envelope follower.

Envelope follower (same structure as original but fed with rms):
attack_coeff = exp(-1.0 / (intensity_attack * sample_rate))
release_coeff = exp(-1.0 / (intensity_release * sample_rate))
If rms > self.envelope: envelope = attack_coeff * envelope + (1.0 - attack_coeff) * rms
Else: envelope = release_coeff * envelope + (1.0 - release_coeff) * rms

Convert envelope to dB: env_db = 20.0 * log10(envelope) (with -96dB floor for near-zero).

Soft knee gain reduction:
knee_half = knee_width_db / 2.0 (knee_width_db is converted back: 20*log10(self.knee_width) or store knee_width as dB internally — use knee_width as f32 representing dB width directly).
knee_low = threshold - knee_half, knee_high = threshold + knee_half.
If env_db > knee_high: gain_reduction_db = (threshold - env_db) * (1.0 - 1.0/ratio).
Else if env_db > knee_low: t = (env_db - knee_low) / knee_width_db; effective_ratio = 1.0 + (ratio - 1.0) * t * t; effective_threshold = knee_low + knee_width_db * t * t * 0.5; gain_reduction_db = (effective_threshold - env_db) * (1.0 - 1.0/effective_ratio).
Else: gain_reduction_db = 0.0.

Convert to linear gain and apply to the OLDEST frame (front of lookahead):
```rust
let gain = 10.0_f64.powf(gain_reduction_db / 20.0);
let front_frame = self.lookahead.front_mut().unwrap();
for s in front_frame.iter_mut() {
    *s *= gain;
    *s *= self.makeup_gain as f64; // D-05 makeup gain
    if !s.is_finite() { *s = 0.0; } // NaN guard
}
```

Output the front frame: copy front_frame values into `frame` slice, then pop_front().

Note: This introduces 1ms latency since we always output the oldest frame from the buffer.
The process_frame signature stays the same.

Important: knee_width should be stored as dB (f32) to match threshold dB domain.
Update update_intensity_params() to store knee_width as the dB value from the table (30, 20, 10, 5, 0).

After implementation run cargo check.
