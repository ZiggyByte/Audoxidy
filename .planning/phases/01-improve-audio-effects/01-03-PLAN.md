Per D-06: Rewrite Limiter::process() in src/audio/dsp.rs.

In process(&mut self, frame: &mut [f64]):

Step 1 — Lookahead push:
Push current frame clone into self.lookahead.push_back(frame.to_vec()).
While lookahead.len() > lookahead_samples: lookahead.pop_front().
If lookahead.len() < lookahead_samples: return early (building buffer).

Step 2 — Extract oldest frame and oversample:
Take front frame: `let oldest = self.lookahead.front().unwrap().clone();` (or use indexing).
Upsample: `self.upsample_4x(&oldest, &mut self.oversample_buffer);`
Now self.oversample_buffer contains the 4x upsampled version.

Step 3 — True peak detection on upsampled data:
`let true_peak = self.oversample_buffer.iter().map(|s| s.abs()).max_by(|a, b| a.partial_cmp(b).unwrap()).unwrap_or(0.0);`

Step 4 — RMS and crest factor:
`let rms_sq = self.oversample_buffer.iter().map(|s| s * s).sum::<f64>() / self.oversample_buffer.len() as f64;`
`let rms = rms_sq.sqrt().max(1e-10);`
`let crest = true_peak / rms;`
`self.crest_factor_smooth = 0.9 * self.crest_factor_smooth + 0.1 * crest;`
`let crest_norm = ((self.crest_factor_smooth - 1.0) / 19.0).clamp(0.0, 1.0);`

Step 5 — Adaptive release:
`let release_secs = 0.1 - crest_norm * 0.09;` (10ms when crest_norm=1, 100ms when crest_norm=0)

Step 6 — Envelope follower (on upsampled data, using 4x sample rate):
`let sr_4x = (self.sample_rate as f64) * 4.0;`
`let release_coeff = (-1.0_f64 / (release_secs * sr_4x)).exp();`
`if true_peak > self.envelope { self.envelope = true_peak; } else { self.envelope = release_coeff * self.envelope + (1.0 - release_coeff) * true_peak; }`

Step 7 — Gain reduction on upsampled buffer:
`let ceiling_lin = 10.0_f64.powf((self.ceiling as f64) / 20.0);`
If self.envelope > ceiling_lin:
  `let attenuation = ceiling_lin / self.envelope;`
  `for s in self.oversample_buffer.iter_mut() { *s *= attenuation; }`

Step 8 — Downsample back to original rate:
`self.downsample_4x(&self.oversample_buffer.clone(), &mut Vec::new(), frame.len())`
Copy result into frame[0..]. Or simpler: after gain reduction, apply decimation (every 4th sample of oversample_buffer) directly to frame. Use the polyphase filter for anti-aliasing during decimation:
For each output index i (0..frame.len()), frame[i] = convolve_phase(oversample_buffer, i*4 + phase_offset, FIR_POLYPHASE[phase]) where phase offset centers the filter.

Step 9 — Pop front from lookahead: `self.lookahead.pop_front();`

Step 10 — NaN guard: `for s in frame.iter_mut() { if !s.is_finite() { *s = 0.0; } }`

After implementation run cargo check.
