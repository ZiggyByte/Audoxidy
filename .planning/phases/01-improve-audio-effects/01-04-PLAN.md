Per D-07 and D-04: Implement Reverb::process() in src/audio/dsp.rs.

The method signature stays: `pub fn process(&mut self, frame: &mut [f64])`.

For each sample in the frame (indexing by channel position `ch`):

1. Select channel-specific state:
   - ch == 0 → delay_lines = &mut self.delay_lines_l, damping_states = &mut self.damping_states_l, pre_delay = &mut self.pre_delay_l
   - ch == 1 → delay_lines = &mut self.delay_lines_r, damping_states = &mut self.damping_states_r, pre_delay = &mut self.pre_delay_r
   - ch >= 2 → reuse L channel (mono fallback)

2. Save original input: `let input_orig = *sample; let input_scaled = input_orig * (self.gain as f64);`

3. Pre-delay: `let fdn_input = pre_delay.read(); pre_delay.write(input_scaled);`

4. Read 16 delay lines and apply damping:
   - `let mut delay_outs = [0.0_f64; 16];`
   - For i in 0..16:
     - `let dout = delay_lines[i].read();`
     - `damping_states[i] = (1.0 - self.damping_coeff) * dout + self.damping_coeff * damping_states[i];`
     - `delay_outs[i] = damping_states[i];`

5. Hadamard feedback mix:
   - `let mut feedback = [0.0_f64; 16];`
   - For i in 0..16:
     - `let mut sum = 0.0;`
     - For j in 0..16: `sum += self.hadamard[i][j] * delay_outs[j];`
     - `feedback[i] = sum;` (Hadamard is already normalized by 1/4 in construction, so no extra division)
   - Note: since hadamard entries are ±0.25, the sum is pre-normalized. The feedback gain is applied next.

6. Write back to delay lines:
   - For i in 0..16: `delay_lines[i].write(fdn_input + feedback[i] * self.feedback_gain);`

7. Compute reverb output as average of delay outputs: `let reverb_out = delay_outs.iter().sum::<f64>() / 16.0;`

8. Equal-power mix (D-04):
   - `let wet_rad = (self.wet as f64) * std::f64::consts::FRAC_PI_2;`
   - `let dry_gain = wet_rad.cos(); let wet_gain = wet_rad.sin();`
   - `*sample = reverb_out * wet_gain + input_orig * dry_gain;`

9. NaN guard: `if !sample.is_finite() { *sample = 0.0; }`

Optimization note: The 16×16 Hadamard multiply can be unrolled by the compiler. With -O2, Rust will optimize the nested loop well. Since all entries are ±0.25, the inner loop is 16 add/sub operations — very fast.

After implementation run cargo check.
