    **1. Modificar la función vertical_slider() para aceptar configuración de estilo de desactivación:**

    El helper `vertical_slider()` actualmente tiene parámetros:
    - label_top, label_bot, value, on_change, on_right_click

    Se recomienda **no** modificar la firma de `vertical_slider()` para mantener compatibilidad con llamadas existentes. En su lugar:

    **Opción A (recomendada):** Agregar un nuevo helper `vertical_slider_eq()` o modificar la función para aceptar un parámetro opcional `disabled_style: bool`.

    **Opción B (más limpia):** Modificar vertical_slider() para devolver el slider sin terminar de construirlo, permitiendo que el caller agregue los estilos.

    **Enfoque recomendado (mínimo cambio):**
    Agregar un parámetro `eq_disabled: bool` a vertical_slider(). Cuando eq_disabled == true, configurar los colores del slider según la tabla de EQ desactivado. La firma sería:
    ```
    fn vertical_slider<'a>(
        label_top: String,
        label_bot: String,
        value: f32,
        on_change: impl Fn(f32) -> crate::gui::app::Message + 'a,
        on_right_click: impl Fn() -> crate::gui::app::Message + 'a,
        eq_disabled: bool,
    ) -> Element<'a, crate::gui::app::Message>
    ```

    **2. Lógica de configuración de estilos según eq_disabled:**

    Dentro de vertical_slider(), después de construir el slider básico y antes de devolverlo en la columna:

    ```rust
    let slider = if eq_disabled {
        slider
            .handle_color(COLOR_CONTRAST)       // #111111
            .border(2.0, COLOR_ACCENT)            // #FF003D, 2px
            .handle_focus_color(COLOR_ACCENT)     // #FF003D (focus visual)
            .handle_hover_color(COLOR_CONTRAST)   // #111111 (clic activo)
            .border_hover(2.0, COLOR_TEXT_SECONDARY) // #5B5B5B, 2px
    } else {
        slider  // EQ activado — colores por defecto (handle=ACCENT, focus=PRIMARY, hover=SECONDARY, etc.)
    };
    ```

    | Campo | EQ Activado (default) | EQ Desactivado |
