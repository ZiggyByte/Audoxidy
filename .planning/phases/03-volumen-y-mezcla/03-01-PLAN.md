**Part A — dsp.rs:** Add two public methods on `DspChain` (after the existing `process_frame` method, before the `Limiter` struct at ~line 1910):

```rust
impl DspChain {
    /// Force limiter on. Returns the previous enabled state for restore.
    /// Used by normalization auto-on (D-25).
    pub fn force_limiter_on(&mut self) -> bool {
        let was = self.limiter.enabled;
        self.limiter.enabled = true;
        was
    }

    /// Restore limiter to its previous user-controlled state.
    pub fn restore_limiter(&mut self, was_enabled: bool) {
        self.limiter.enabled = was_enabled;
    }
}
```

The `self.limiter.enabled` field already exists at `dsp.rs:1928` (Limiter struct, `enabled: bool`). The Limiter's ceiling stays at -1.0 dBTP — no changes to Limiter struct needed.

/// Force limiter on (for normalization auto-on per D-25).
/// Returns the previous limiter enabled state.
pub fn force_limiter_on(&self) -> bool {

pub fn restore_limiter(&self, was_enabled: bool) {
