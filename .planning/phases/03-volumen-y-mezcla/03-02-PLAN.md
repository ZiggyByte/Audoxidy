```rust
/// Strip known unit suffixes from a numeric string before parsing.
/// Used by CustomSlider and NumberStepper for keyboard input.
fn strip_suffix(s: &str) -> &str {
    s.trim()
        .trim_end_matches(" dB")
        .trim_end_matches(" ms")
        .trim_end_matches(" Hz")
        .trim_end_matches(" %")
        .trim()
}
```

**Fix 2 — Enter key (line ~3141):** Replace `state.input_value_text.parse::<f32>()` with `strip_suffix(&state.input_value_text).parse::<f32>()`. Keep the rest of the Enter handler logic unchanged (the snapping/clamping logic at lines 3143-3148 stays).

**Fix 3 — Click-outside (line ~2963):** Same replacement: `state.input_value_text.parse::<f32>()` → `strip_suffix(&state.input_value_text).parse::<f32>()`. Do NOT change the snapping logic — CustomSlider still snaps to configured step.

**Fix 4 — Character filter at line ~3179:** In the `Key::Character(c)` arm of the keyboard match, replace the existing character insert logic with a filtered version:

```
iced::keyboard::Key::Character(c) => {
    // Only accept: digits, '.', '-', whitespace (for suffix separation)
    // Max 20 chars to prevent buffer bloat
    if state.input_value_text.len() < 20 {
        let ch = c.chars().next().unwrap_or(' ');
        if ch.is_ascii_digit() || ch == '.' || ch == '-' || ch.is_whitespace() {
            state.input_value_text.insert(state.input_cursor_pos, ch);
            state.input_cursor_pos += 1;
        }
    }
}
```

This prevents entry of non-numeric characters (`e`, `+`, letters, etc.) while allowing the decimal point, minus sign, and whitespace for suffix separation. The existing `Backspace` handler (lines ~3185) is NOT modified — it stays as-is.

**Fix 5 — Add Delete key support:** After the Backspace arm (before or after it), add:

```
iced::keyboard::Key::Named(iced::keyboard::key::Named::Delete) => {
    if state.input_cursor_pos < state.input_value_text.len() {
        state.input_value_text.remove(state.input_cursor_pos);
    }
}
```

This is missing from the current CustomSlider — Delete is a standard text-editing key. Not strictly required by D-45 but included for consistency with NumberStepper (D-34).

**IMPORTANT:** The CustomSlider still snaps values to the configured step on Enter/click-outside. Only the suffix stripping is added. Do NOT remove the snapping — this is the existing behavior.
