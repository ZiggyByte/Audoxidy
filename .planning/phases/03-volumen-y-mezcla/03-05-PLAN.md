New code:
```rust
Message::VolumeChanged(vol) => {
    self.audio_manager.set_volume(vol);
    // Fix B3 (D-43): persist volume across restarts
    if let Ok(db) = self.database.lock() {
        let _ = db.set_setting("player_volume", &format!("{:.4}", vol));
    }
    Task::none()
}
```

**DB lock handling:** The `self.database` field is `Arc<Mutex<Database>>` per the AGENTS.md conventions. Use `self.database.lock()` (blocking) — the GUI thread can block briefly on DB write. The `let _ =` ignores Result errors (DB write failure should not crash the app).

**Format:** `format!("{:.4}", vol)` gives 4 decimal places for f32 precision (e.g., `0.3000`). This is sufficient to restore the exact volume value.
